# Bash Scripting Sandbox 🐚

Welcome to my Bash scripting repository! This collection contains various shell scripts I've written to learn, practice, and automate tasks. 

## 📖 About This Repository
As part of my work in system and network administration, I use this space to experiment with Bash commands, control structures, and automation techniques. The scripts range from basic commands to more complex logical operations, serving as a personal reference for shell scripting.

The repository consists of sequentially named scripts covering different concepts:
- **Basic Output & Variables:** `first.sh`, `second.sh`, `third.sh`

- **Advanced Operations:** `fifteen.sh`, `sixteen.sh`, `eighteen.sh`, `twone.sh`
